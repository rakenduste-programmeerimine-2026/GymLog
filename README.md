# GymLog

Jõusaalitreeningute logimise rakendus – kursuseprojekt (rakenduste-programmeerimine-2026).

Kasutaja saab salvestada treeninguid (harjutused, kaalud, kordused), näha treeningute ajalugu ning vaadata statistikat kalendri- ja detailvaates.

## Projekti struktuur

- [`client/`](client/README.md) – frontend (React + Vite + TypeScript)
- [`server/`](server/README.md) – backend (Node.js + Express REST API)
- [`database-README.md`](database-README.md) – andmebaas (Supabase) ja selle seadistus

## Tiim

- **Frontend**: React
- **Backend**: Node.js / Express
- **Andmebaas**: Supabase (PostgreSQL + Auth)
